# 0.3.1 local test validation

Validated on 2026-10-12 against the installed Valheim managed assemblies and Unity 6000.0.75f1, using BepInEx 5.4.23.5.

- `test.ps1 -RenderPreview`: **6,064 checks passed**, 1440×1080.
- `test.ps1 -RenderPreview -PreviewWidth 800 -PreviewHeight 900`: **6,064 checks passed**, 800×900.
- Both previews were visually inspected. The longer master-switch label fits, the frame is complete, and the inventory controls remain clear.
- An isolated native network fixture exercises the actual authenticated controller and object toggle RPCs. Missing saved values default Off; master and object switches gate supplies independently. Invalid sender identity, unknown actors, distant actors and dead actors cannot change the object switch.
- Native ZDO serialization preserves individual On and Off choices. Turning either switch Off invalidates an automatic transaction before it can commit. The production hover decorator preserves the native prompt and adds the configurable object control.
- Real native charcoal-kiln conversion lists accept normal Wood and charge exactly one item. Core wood, fine wood, ancient bark, Yggdrasil wood and ashwood remain untouched by manual VSS supplies and automatic supplies, even with an empty configurable exclusion list. Coal and resin remain allowed.
- Existing resource-payment, crafting/building, direct consumption, station-capacity, storage-conservation, equipment, chest-lease, bundle and UI diagnostics still pass.

Fixtures use temporary inventories, synthetic network objects and a separate save directory. They do not open or modify an existing character/world. Vanilla reference sprites and decompiled inspection files remain excluded from the repository and release ZIP.

The author previously tested 0.2.4 in co-op. **The new 0.3.1 features still require live multiplayer testing.** Follow `COOP-CHECKLIST.md` with the same build installed on every player and host/server before publishing this update.
