# 0.4.0 machine collection validation

Validated on 2026-10-13 against the installed Valheim managed assemblies, Unity 6000.0.75f1 and BepInEx 5.4.23.5.

- Separate headless runtime: **6,293 native checks passed**.
- Rendered UI at 1440×1080 and 800×900: **6,322 checks passed in each run**; inspected both previews. The two master buttons fit the header without overlapping the title, capacity label or close button.
- Real native kiln `Smelter.Spawn` creates an exact tagged coal stack. The spawn scope restores afterward, and the native ground auto-stack path leaves unrelated untagged coal separate. Collection deposits the emitted quantity once.
- Saved machine/source ZDO flags serialize and replicate correctly. Native object/master RPCs validate sender ownership, actor identity and interaction distance. Collection is independent of refill and starts Off at both levels.
- Cooking diagnostics cover raw-food rejection, cooked/burnt output identity, world/cheat flags, compatible partial stacks, full destinations, slot clearing and visual RPCs. A second collection cannot repeat a cleared output.
- An actual owner-side chest lease transaction prioritizes a farther compatible stack over a nearer empty chest, releases its lease and persists the exact output through native chest serialization. Busy/full destinations leave the cooking output available.
- Ground output tests verify partial deposits, preserved remainders, object/master cancellation, output moved away from its source, and destruction only after the final amount is transferred. Output ownership requests use the native retry/backoff behavior.
- Key migration moves only the old unmodified G default to F6, preserving other custom shortcuts. Collection defaults to F7. G remains available for Valheim's radial menu.
- Existing transfer conservation, chest preferences, protected woods, crafting/building, station supply and performance checks remain passing. The 60-chest/3,000-stack stress fixture performs repeated building and recipe reads with zero additional controller searches/cache refreshes; hover formatting is reused.

These are synthetic native fixtures and rendered previews, not an FPS measurement or a live multiplayer world test. Live collection owner handoffs, disconnection, save/rejoin and simultaneous player activity remain on the updated `COOP-CHECKLIST.md`.

Automatic collection operates on loaded pieces. Unmarked drops emitted before collection was enabled remain for manual pickup. Full storage leaves food on its rack, so native overcooking can still occur.
